# Morse Lab

A simple, browser-based Morse code learning and translation tool.

## Features

- **Morse Translator** — Translate text into Morse code and Morse code back into text.
- **Alphabet Cheat Sheet** — Browse letters, numbers, and punctuation with their Morse representations.
- **Audio Playback** — Listen to Morse code signals directly in your browser.
- **Learning Guide** — Learn the basics of Morse code, signal timing, and common patterns.
- **Responsive Design** — Works on desktop and mobile screens.

## Getting Started

No installation or dependencies required.

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start translating!

You can also use a local development server if preferred.
